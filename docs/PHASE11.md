# Phase 11: bounded RAG quality and offline evaluation

Phase 11 keeps PostgreSQL + pgvector and SQL owner filtering. Retrieval takes at most 30 vector candidates by default (never more than 40), then uses a deterministic small lexical-overlap bonus to rank them, filters an optional cosine similarity threshold, and suppresses identical normalized chunk text. Ties resolve by score, document ID, chunk index and chunk ID. This is not a new network or SQL-generation tool.

RAG packs only selected source text into a bounded 6,000-character context by default (at most 10 chunks, 800 text characters each). The response names only sources actually included. Empty retrieval/answer returns explicit insufficient evidence. These are provenance and context controls, **not proof that an arbitrary external LLM never hallucinates**; an externally generated statement still needs human review. Agent document-search decisions with no evidence cannot be classified as RAG-grounded. Owner filtering occurs in the database query before candidate reranking; existing PostgreSQL integration tests protect cross-user isolation.

The version-controlled offline suite now includes relevance/duplicate/threshold and fake-provider streaming cases in addition to RAG/source, tool rejection/selection, bounded agent steps and safe provider failures. `METRIC rag_pass_rate`, `tool_pass_rate`, `agent_pass_rate`, and `stream_pass_rate` are the fraction of deterministic cases passing in each category, **not** live retrieval hit rate or model-grounding accuracy. No paid APIs, live LLM scoring or LLM-as-judge are used. Both CI pytest and the runner execute without provider credentials.

Limitations: lexical overlap is deliberately small and English-oriented; cosine threshold defaults to -1 for backward compatibility and should be tuned using representative owned documents. Source references indicate evidence included in context, not independent factual verification of model output. No UI redesign was needed; existing source filename/chunk/similarity presentation remains.
